# 改版遗漏的设计 · 2026-09-30

起因：用户指出，新版文章页丢了旧版目录的细致交互，比如读到一半往回划就能看到目录，要求参照旧代码补回，并查找其他遗漏。

比较对象：改版前为 `cd69971~1`，改版后为 `7b1ad04`。一位只读审查员先对比两版代码，再在无头 Chrome 中测量，视口为 390 宽的手机和 1440 宽的桌面。实现后用 Playwright 在 390×844（移动端模拟）和 1280×900 下复核，深浅色都看过。

## 本次补回（文章页）

| 设计 | 旧版 | 改版后 | 现在 |
|---|---|---|---|
| 手机目录跟随阅读 | `mobile-scroll-ui.ts`、`toc-generator.ts`：目录吸顶；下划时隐藏，上划超过 8px 就出现；越过 `max(200px, 0.6×视口高)` 后才隐藏；5 秒不动自动隐藏；展开时不隐藏；点外面收起；回到顶部按钮随之隐现。 | 目录框留在标题下方的原位，读过去就找不到了。回到顶部按钮越过 600px 后一直显示。 | 目录框吸在页头下方，隐藏条件和各项时间与旧版相同。起点改为目录框贴到页头的那一刻，这时它不再占据原位。展开时回到顶部按钮让开，避免压住列表。键盘焦点在框内时不隐藏，Esc 收起。 |
| 展开目录不推动正文 | 旧版目录吸顶后展开，列表插进文档流，正文会被推下去。依赖浏览器的滚动锚定补偿，Safari 上不一定有。 | 不吸顶，问题不存在。 | 在页头下展开时，列表浮在正文之上，页面不动。实测：锚点段落位置和 `scrollY` 展开前后一致。原位展开仍像以前一样推开正文。长目录在框内滚动，不超出屏幕。 |
| 当前小节的读屏标记 | 当前目录项带 `aria-current`。 | 只切换 class。 | 当前项带 `aria-current="location"`。手机上点目录跳转后，当前项同步更新。 |
| 目录层级 | 目录含 h2–h4，手机上也分层级缩进。 | 只收 h2、h3；手机目录框的内边距覆盖了 h3 缩进，层级被压平。 | 收回 h4。两篇哈巴雪山文章每种语言各多 4 项。手机上 h3、h4 分别缩进 16px、32px。 |
| 跳转落点 | 目录不压住标题。 | 标题和脚注的 `scroll-margin-top` 是 96px，只避开页头。 | 手机上改为页头高度加 64px（目前是 140px），标题和脚注落在目录框下方。 |
| 脚注返回图标 | 描边箭头。 | 生成器仍输出 SVG，但 CSS 缺描边规则，箭头显示为实心黑块，深色模式下几乎看不见。 | 补回描边规则。 |
| 脚注编号的点击区域 | 20×20 的着色圆点。 | 手机上 8×14px 的纯文字。 | 外观保持新版，另加一个看不见的点击区，约 30×38px。 |
| 从脚注回到正文 | 返回后正文里的编号高亮 1.6 秒，并保持 `:target` 样式。 | 返回链接没有脚本处理：瞬间跳回，没有高亮，也不移动焦点。 | 返回时平滑跳转并移动焦点，编号高亮。页面停止滚动 1.8 秒后高亮才褪去，长距离跳转到达时仍看得见。去脚注的方向同样如此。 |
| 文末区块的标题 | 系列、标签、反链用 `<h3>`。 | `<span class="k">`，读屏无法按标题跳转。 | 改为 `<h2 class="k">`，外观不变。1280 和 390 两种宽度下，两篇文章文末区域的截图与改前逐像素相同。 |

未补回：旧版目录的第一项是文章标题，作用相当于“回到顶部”。新版已有回到顶部按钮，所以不加。

## 待定：涉及改版取舍

以下是改版有意或无意改变的地方，需由用户决定。标注“量”的已在浏览器中测量，其余只读了代码。

| 问题 | 证据 | 可选做法 |
|---|---|---|
| 手机页头始终吸顶 | 旧版导航不吸顶。量：390×664 下，页头 76px 加回到顶部按钮 48px，约占视口 11%。按钮已随本次改动隐藏，页头仍在。 | 让页头也随下划隐藏、上划出现，与目录框一起动。 |
| Articles 列表的标题不再是链接 | 标题现在是展开摘要的按钮，唯一的链接“阅读”在摘要里。打开一篇文章要点两次，标题也不能用 Cmd 点击或中键在新标签页打开。 | 标题改回链接，由“+”负责展开。 |
| 主题切换没有“跟随系统” | 旧版在自动、深、浅三态间循环。新版只在深浅之间切换，点过一次就不再跟随系统。 | 恢复三态；或者选中的模式与系统相同时，清掉保存的选择。 |
| Favorites 长短评按字数折叠 | 旧版按渲染行数折叠：隐藏至少 2 行才折叠，窗口尺寸变化时重新测量。量：用旧规则套新版布局，390 宽下有 12 条 10–17 行的短评不折叠（书 5、影 2、游戏 5）；1440 宽下有 1 条。 | 恢复按行测量，或在字数规则里计入换行。 |
| About 邮箱没有 `mailto:` | 现在只有复制按钮，没有脚本时无效，复制成功也不播报。 | 地址改为 `mailto:` 链接，旁边另放复制按钮。 |
| 外链 `rel` 被整个覆盖 | `markExternal` 把 `rel` 直接设为 `noopener`，已有的 `me`、`noreferrer` 等值会丢失。 | 在原有值上追加 `noopener`。 |
| 旧的 Work、Favorites 锚点失效 | 例如 `gallery.html#gallery-talks`、`favorites.html#favorites-books`。新版 id 不同，Work 没有别名映射；Articles 有。 | 加一张旧锚点到新 id 的别名表。 |
| 标签筛选不进浏览器历史 | 改用 `replaceState` 后，按返回键不能撤销筛选。 | 筛选改用 `pushState`。 |
| 首页作品轮播不能暂停 | 自动轮播只在悬停或聚焦时暂停，触屏上没有暂停控件（WCAG 2.2.2）。 | 加一个暂停按钮。 |

## 顺带发现，与改版无关

- 注解预处理先于 `fenced_code` 运行，代码块里的 `[[...]]` 被改写成字面的 `<span class="annotated-word">` 文本。见 PKM 2026-03 一文，改版前后都有。
- RSS 中原先的 GIF 位置现在是 `<video>`，中英文各 7 处。过滤视频的阅读器只会显示替代文字。由 3823cdb 引入。

## 限制

没有在真机、Safari 或读屏软件上验证。Safari 的滚动锚定行为是从规范推断的，这也是列表在吸顶时改为浮层的原因。

# 数据、信息、知识、智慧

![DIKW 金字塔：青色的三角形自下而上分为 DATA、INFORMATION、KNOWLEDGE、WISDOM 四层](assets/images/data-information-knowledge-wisdom/49151acd148b7f9575893df977dfcfdf.png)

DIKW体系

上图为DIKW体系，一个分为数据、信息、知识、智慧四层的金字塔结构。整个过程也可以大致概括为**自底向上，再自顶向下。**

数据是信息的实际载体，信息通过对数据的处理得到。数据无对错，但得到的信息可能会是错的（无法反映真实的情况）。特别是在噪声比较强的环境下的数据，更容易使信息出错。各种信息来源参差不齐，真正有价值的信息往往被裹挟在大量冗余、错误且一直呈爆炸性增长的信息之中。

知识是有价值的信息（定义见世界银行《1998年世界发展报告－知识促进发展》），是经过筛选后留下来的信息，按此定义来看，知识也有对错之分。从宏观上来讲，新的数据、信息的出现将可能使正确的知识得到扩充，而谬误的知识则有被推翻的可能性。我们现在所能见到的人类庞大的知识体系，是长期的迭代过程产生的良好结果。而站在个体的角度，每个人的精力和能力是相当有限的，**饥不择食（质）、暴饮暴食（量）的后果往往便是难以消化，甚至腹痛腹泻**，这对个体来说当然有害。

如果上升到智慧层面，我认为能够直接从外界获得的，最高也就到知识这一层，**智慧只能由自我产生。**无论是阅读还是什么，从外界获得是必要的，可是如果单纯获取而不消化吸收，那便白费，产生不出丁点智慧。
